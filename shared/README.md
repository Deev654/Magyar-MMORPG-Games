# Shared modul

A kliens és a szerver között megosztott erőforrások, például Protocol Buffers definíciók, DTO-k és közös segédfüggvények.

## Következő lépések
- `proto/` mappa létrehozása a szerződéseknek.
- Generációs scriptek beállítása (`pnpm proto:generate`).
- Validációs és utility modulok kialakítása.
